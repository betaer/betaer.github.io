浏览器安全工具

两个可以直接使用、也可以公开审计的独立项目。

网络与浏览器隐私检测

AI Signal Guard

检查公网 IPv4/IPv6、DNS、WebRTC、浏览器指纹和 AI 服务连通性，并如实展示来源、失败与超时。

处理边界
本地整理检测结果，部分检测请求第三方公开服务。
打开 AI Signal Guard 查看源码

本地密码与记忆短语生成

Password Generator

使用 Web Crypto API 在浏览器本地生成随机密码、记忆短语和 PIN，并根据实际结果分析强度。

处理边界
密码、PIN、记忆短语和输入内容不会发送到项目服务器。
打开 Password Generator 查看源码

共同的安全原则

浏览器优先
能够本地完成的处理，不交给远程服务。
敏感数据本地处理
密码、PIN 与记忆短语不会发送到项目服务器。
公开可审计
项目代码与关键安全边界可以直接检查。
说明能力边界
检测结果和强度估算不包装成无法验证的承诺。
