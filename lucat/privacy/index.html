猫咪的日常，留在您的设备上。
这份说明解释 LuCat 处理哪些信息，以及您可以如何管理它们。

1. 我们处理哪些信息

LuCat 用于管理猫咪资料、体重及撸猫记录。当前版本无需注册 LuCat 账号。使用不同功能时，App 会在设备上处理：

  • 猫咪资料：您填写的名称、品种等档案内容、选择或拍摄的头像，以及体重和测量日期。
  • 撸猫记录：关联猫咪、开始与结束时间、时长，以及 Apple Watch 采集的手腕运动数据和据此生成的统计、曲线与动作分析结果。
  • 使用设置：语言、每日目标、提醒时间、示例数据状态及其他偏好。
  • 运行与同步信息：设备间传输状态、错误及本地诊断日志，用于排查故障和避免重复、遗漏同步。

上述信息用于呈现您选择的功能。猫咪资料与运动记录不会由当前版本自动上传到 LuCat 开发者的服务器。当前版本不提供麦克风录音、心率采集、广告追踪或云端 AI 分析。

示例猫咪与示例记录属于内置演示内容，不代表真实采集的数据。请不要在猫咪名称、头像或其他字段中填写不必要的个人敏感信息。

2. 权限由您决定

  • 相机：用于主动拍摄猫咪头像。
  • 照片：用于选择猫咪头像。可访问的照片范围由您在系统授权界面中决定，App 以您实际选择的图片作为头像。
  • 运动相关访问：用于 Apple Watch 记录与分析手腕运动，按系统要求请求相关权限。
  • 通知：用于在您设置的本地时间提醒您撸猫，通知可能包含猫咪名称和头像。

您可以拒绝授权，或在 iOS / watchOS 系统设置中修改权限。拒绝某项权限会影响对应功能，但不等于自动删除此前已保存的数据。系统通知可在锁定屏幕出现，请按需调整通知预览。

3. 数据保存与设备同步

猫咪档案、记录与相关文件主要保存在 iPhone 和 Apple Watch 的 App 本地存储中。配对设备通过 Apple 提供的设备通信机制同步；手表断开连接时，尚未同步的数据可能继续保留在手表上，待连接恢复后处理。

头像可能生成缩略图用于手表显示或本地通知附件。修改或删除资料后，配对设备上的变化取决于同步是否完成；已送达的系统通知或您已导出的文件不会因此自动从所有位置撤回。

当前 App 未提供 LuCat 账号云备份或开发者服务器同步。设备系统自身的备份、恢复及诊断服务由 Apple 和您的系统设置管理，不应把“本地保存”理解为设备上所有副本均绝对不会进入系统备份。

4. 管理、留存与删除

您可以在 App 中查看、编辑相关资料，关闭提醒或使用提供的删除、清空功能。配对设备离线时，设备间的删除处理可能需要恢复连接后完成。

当前代码中的归档与清空并不完全等同于永久擦除：归档猫咪会隐藏档案，但可能保留关联的历史记录；部分清空流程会把数据移至本机隔离存储以完成跨设备操作。因此，此草稿不承诺点击一次“删除”即可立即清除两台设备上的全部副本。正式发布前将进一步核对实际入口、留存期限与清除方式，并据此更新本节。

卸载与“卸载但保留文稿和数据”并不相同。若希望清除设备上的 App 数据，请使用系统的删除 App 操作，并检查配对手表、已有导出文件及系统备份。开发者不能远程访问或替您擦除未提交给开发者的本地数据。

5. 分享、反馈与外部网页

只有在您主动使用分享、导出或反馈功能并完成相应操作后，所选内容才会交给您选择的接收方或服务。请在发送日志、截图或记录前检查其中的信息，接收方的保存和使用受其规则约束。

App 中的问题反馈、社群及开发者社交链接会打开腾讯文档、X、抖音、小红书等第三方服务。这些服务可能按各自政策处理账号、网络地址及您提交的内容；LuCat 不会因您打开链接而自动附加猫咪档案或运动记录。

本隐私说明页面由 GitHub Pages 托管。网页没有接入额外广告、分析脚本或追踪 Cookie；访问网页本身仍会向托管服务发送 IP 地址等网络请求信息，详见 GitHub 隐私声明。URL 中的语言参数只用于选择页面语言，不包含猫咪资料。

6. 安全与未成年人

App 使用系统沙盒与可用的文件保护机制，并校验设备间传输的数据。但任何设备或传输方案都无法保证绝对安全，请保护设备解锁凭据并及时更新系统。

LuCat 当前没有专门面向儿童的账号或社交功能。未成年人应在监护人指导下使用，不应通过头像、反馈或外部社群披露自己或他人的敏感信息。

7. 联系与政策更新

如需就 LuCat 的数据处理提出问题，可使用现有 问题反馈入口（腾讯文档）。请勿在可能公开的文档中提交密码、身份证件或其他敏感信息。

正式运营主体与专用隐私联系渠道将在确认后补充。政策如因功能变化而修订，将在本页标明新的更新日期；需要额外授权的功能应在使用前说明并请求相应权限。
